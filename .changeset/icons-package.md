New package: `@booki-aui/icons`, 123 duotone icons for accounting, auditing, AI and agent UI. Each icon is a named React component (`BanknoteIcon`), `iconSvg(name)` gives a complete SVG for any framework, and the plain files are at `@booki-aui/icons/svg/<name>.svg`. `COVERAGE.md` lists every icon by theme and what it stands for; browse and search them at booki.dev/docs/icons.
